# 快速上手 · 本地开发链路（队友 / 二次开发专用）

> 这条路不经过 Docker，直接在本机跑源码，改代码即刻生效。
> 需要 Python 3.11+ 和 Node 20+。只想跑起来看效果请走
> [快速上手_Docker链路.md](快速上手_Docker链路.md)。

## 前置检查（1 分钟）

```bash
python --version    # 期望 ≥ 3.11（python3 --version 也行，取决于系统）
node --version      # 期望 ≥ 20
```

- 版本不够或 `command not found`：先装对应运行时再继续。
- Windows 上 `python` 打不开微软商店的话，用 `py --version` 或 `python3 --version`。

## 第 1 步：克隆并进入项目目录（后面所有命令都在这个目录里执行）

```bash
git clone https://github.com/hanbin123-creator/cost-insight.git
cd cost-insight
```

⚠️ **队友实测踩坑第一名**：漏了 `cd cost-insight`，在主目录直接跑后面的命令，
就会报 `Could not open requirements file` 和 `系统找不到指定的路径`。
先执行 `pwd`（Windows CMD 用 `cd` 单独回车）确认路径以 `cost-insight` 结尾。

## 第 2 步：放好考题数据包

数据包属赛题保密资源，**不在仓库里**，放到本仓库的**同级目录**：

```
你的文件夹/
├── cost-insight/            ← 刚克隆的仓库
└── 创灵境_考题模拟数据/      ← 考题数据包放这里（与仓库同级）
```

放别处则设环境变量：`COST_INSIGHT_DATA_DIR=数据包绝对路径`。
找不到数据包时启动会给出中文指引（不是裸堆栈），照做即可。

## 第 3 步：装依赖并启动后端

```bash
pip install -r requirements.txt
python -m uvicorn app.api:app --host 127.0.0.1 --port 8000
```

**首次启动会自动构建知识库索引（约 30 秒，仅首次）**，看到这样的日志是正常现象，不是卡住：

```
[kb] 索引缺失，正在从 ... 现场构建（约 30 秒，仅首次）...
[kb] 索引构建完成：351 块 → ...
```

之后看到 `Application startup complete` 即后端就绪。**此窗口保持开启。**
想手动重建索引：`python -m app.kb`（幂等，已存在会提示无需重建）。

## 第 4 步：启动前端（另开一个终端）

```bash
cd cost-insight/web        # 新终端里同样先进入仓库目录
npm ci
npm run dev
```

看到 `Local: http://localhost:5173/` 即就绪（5173 端口已配代理转发到 8000 后端）。

## 第 5 步（可选）：整改闭环的 mock RPA（再开一个终端）

```bash
cd ../创灵境_考题模拟数据/05_RPA接口文档
python mock_rpa_server.py    # 8090 端口
```

不起 mock RPA 也能跑——整改下发会如实标注"RPA 未连接"降级，不放假成功。

## 确认启动成功

| 检查 | 方法 | 预期 |
|---|---|---|
| 看板 | 浏览器打开 http://localhost:5173/ | "成本看板"正常渲染，3 产品 × 6 个月 |
| 后端 | http://localhost:8000/docs | FastAPI 文档页 |
| 索引 | 后端日志 | 出现"索引构建完成"或启动无报错 |

## 撞坑速查表（报错原文 → 原因 → 解法）

| 报错原文 / 现象 | 原因 | 解法 |
|---|---|---|
| `ERROR: Could not open requirements file: [Errno 2] No such file or directory: 'requirements.txt'` | 没执行 `cd cost-insight`，人在主目录 | `cd cost-insight` 后重跑 |
| `No module named uvicorn` | 依赖没装（或装到了别的 Python 环境） | 先 `pip install -r requirements.txt`；多 Python 共存时用 `python -m pip install -r requirements.txt` 确保装到当前解释器 |
| `系统找不到指定的路径。`（执行 `cd web` 时） | 同上，没在仓库根目录 | 回到 `cost-insight/` 再 `cd web` |
| `error while attempting to bind on address ... 8000` | 8000 端口被占 | 换端口：`--port 8001`，同时前端 vite 代理目标同步改 |
| 启动报"找不到知识库语料目录"中文提示 | 数据包没放好 | 按第 2 步摆放，或设 `COST_INSIGHT_DATA_DIR` |
| 知识库/报告相关接口报"报告模板缺失" | 官方模板没复制（保密资源不入库） | 把数据包 `04_报告模板/月度成本分析报告模板.docx` 复制为仓库内 `assets/report_template.docx`；其余功能不受影响 |
| 前端 `npm ci` 报证书 / 超时 | 公司网拦截或默认源慢 | `npm config set registry https://registry.npmmirror.com` 后重跑 |

## 跑测试（改代码前后都建议）

```bash
pytest tests/                  # 后端 174 项
cd web && npm run test         # 前端 76 项
```
