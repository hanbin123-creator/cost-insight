## D1 F9 对标分析页（`BenchmarkView.vue` + `butterflyOption`）

- **决策**：主视图蝶形（龙卷风）图——中轴要素、左展一厂（CT.main 深海军蓝）、
  右展二厂（新增 token CT.peer 同族浅蓝，明度区分两方）；对称量程、轴刻度取绝对值、
  悬浮显示双向差异率。下方依次：双向口径明细表（对二厂/对一厂两列并列，方向红绿徽章）、
  口径描述列表（代码预生成句直接渲染）、材料差异下钻表（估算口径显著标注）。
- **纪律判定**：一厂值取负仅作"显示镜像"，与轴标签短化同级，不是数据计算——
  差异率、描述句全部后端算好，本页只读。
- **优点**：两厂强弱一屏可比；双向口径并列展示从根上杜绝"分母翻错"的读数歧义
  （这正是当初双向口径设计的落地场景）；描述句可直接引用进报告。
- **缺点**：单位成本（≈11）与要素（≈1.5–7.3）同图量程悬殊，要素柱较短——
  实测仍清晰可辨，保留（总量对比是对标页 headline）；材料下钻是占比分摊估算
  非逐料实测，已在板块标题旁常驻标注。
- **验证**：单测锁镜像不变式（s1=-main、s2=bench）、对称量程、双方配色；
  DOM 实测 4 板块渲染、明细 4 行 + 材料 6 行、描述 4 条。

## D2 F6 归因报告分栏对照（`AttributionPanel.vue` 重构 + `figures.ts`）

- **决策**：左栏正文（summary/原因/建议）中的数字段经 `tokenizeFigures` 切成可点按钮
  （主色虚线下划线，暗示"有证据"）；右栏证据列按原因列出 figures 芯片 + citations 出处。
  点击正文数字 → 右栏同值芯片高亮（outline + 光晕）并滚动定位；未登记的数字
  （如"2026"年份）给出 2.6s 提示而非静默。
- **优点**：评审核心卖点"大模型说的每个数字都有出处"在 UI 层可交互验证——
  与后端校验闭环（C2 纪律）形成"系统校验 + 人工点验"双保险；rejected 拦截分支
  原样保留，演示模式（503→fixture）照常工作。
- **缺点**：数字匹配按"值相等"，同值多处出现时全部高亮（语义上正确——它们确实是
  同一个数）；tokenizer 会把年份、编号也切成按钮（未命中时给提示兜底，不是错误）；
  窄内容区（<700px）分栏退化为上下堆叠（容器查询，与主从布局同一降级体系）。
- **验证**：E2E 实测——点正文"11.21"→右栏芯片"11.21"高亮（litCount=1）；
  点"2026"→未命中提示正常；演示模式标签、校验徽章、自动补全声明均在。
