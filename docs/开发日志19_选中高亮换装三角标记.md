# 开发日志 19 · 选中高亮换装：方案一 左上角小三角（Excel 批注风）

日期：2026-09-21 · 范围：`web/src/components/HeatTable.vue`、`web/src/views/DashboardView.vue`（hint 文案）、选型页 `前端选型/选中高亮选型.html`

## 决策（四段式）

- **决策**：热力表"当前看板所选"高亮从"主色描边+柔光晕影"换装为**方案一：左上角 9px 主色小三角**（用户从 5 套方案中选定）。`.cell.sel::before` 纯 CSS 伪元素实现，零 JS；hint 文案同步改为"左上角 ◤ 三角 = 当前看板所选"。
- **优点**：色阶底色与数字 **0 遮挡**（描边会吃 2px 内缘、晕影会干扰色阶判读，三角完全不碰数据区）；财务用户对 Excel 批注三角天然熟悉；实现仅 7 行 CSS，无任何重排/抖动风险。
- **缺点**：标记存在感弱于描边——投影演示、远距离观看时不如方案四/五抢眼（缓解：hint 常驻说明 + hover 仍有主色细框引导）；三角颜色固定主色，若未来主题换色需同步（已是 token 引用色值，改动单点）。
- **裁决**：接受。用户痛点是"丑"，克制的标记正中需求；存在感弱点由 hint 与 hover 补位。
